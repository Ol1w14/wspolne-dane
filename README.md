
# 📋 Wspólne dane – sprawdzanie list imion

## 📖 Opis projektu
Program napisany w języku C++, który porównuje dwie listy imion zapisane w plikach tekstowych. Tworzy raport zawierający imiona wspólne oraz imiona występujące tylko na jednej z list.

## ⚙️ Funkcje programu
- 📂 Wczytywanie imion z plików `lista1.txt` i `lista2.txt`.
- 🔍 Porównywanie dwóch list zawierających po 10 imion.
- 🤝 Wyszukiwanie imion wspólnych.
- 📝 Wyszukiwanie imion występujących tylko w pierwszym pliku.
- 📝 Wyszukiwanie imion występujących tylko w drugim pliku.
- 💾 Zapisywanie wyników do pliku `wynik.txt`.

## 💻 Wykorzystane technologie
- 🚀 C++
- 📚 Biblioteki: `iostream`, `fstream`, `string`
- 📄 Obsługa plików tekstowych

## 📁 Pliki projektu
- `main.cpp` – kod źródłowy programu.
- `lista1.txt` – pierwsza lista imion.
- `lista2.txt` – druga lista imion.
- `wynik.txt` – raport z porównania list.
- `README.md` – opis projektu.

## ▶️ Jak uruchomić program?
1. 📂 Umieść pliki `lista1.txt` i `lista2.txt` w folderze programu.
2. ✍️ W każdym pliku wpisz 10 imion, każde w osobnym wierszu.
3. ⚙️ Skompiluj i uruchom program w środowisku obsługującym C++.
4. 📊 Otwórz plik `wynik.txt`, aby zobaczyć wyniki.

## 📊 Wynik działania
Program generuje raport zawierający trzy sekcje:
- ✅ **IMIONA WSPÓLNE** – imiona występujące na obu listach.
- 🔹 **TYLKO W PLIKU 1** – imiona występujące tylko na pierwszej liście.
- 🔹 **TYLKO W PLIKU 2** – imiona występujące tylko na drugiej liście.
